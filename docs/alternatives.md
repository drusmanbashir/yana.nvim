# Alternatives

Other Neovim plugins that bring a coding agent into the editor:

- [avante.nvim](https://github.com/yetone/avante.nvim): a sidebar chat that proposes edits for you to apply, with many model providers.
- [codecompanion.nvim](https://github.com/olimorris/codecompanion.nvim): chat and inline assistants over many providers and agent CLIs.
- [sidekick.nvim](https://github.com/folke/sidekick.nvim): runs agent CLIs such as Claude, Codex and Cursor alongside Neovim, with next-edit suggestions.
